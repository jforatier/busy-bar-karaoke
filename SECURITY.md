# Security policy

## Supported versions

Only the latest release, the one in the BUSY Apps Catalog, gets fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub: **Security → Report a vulnerability** on this repository. You will get an answer within a week.

## Scope

The app runs on the BUSY Bar only: it makes no network request, stores no personal data (just the last song played), and talks only to the bar's local API. What protects it, and the risks accepted, are described in [specs/11](specs/11-security.md). Issues in the BUSY Bar firmware or its tools belong to [BUSY](https://busy.app).
