# Code of Conduct

This project adopts the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/) as its code of conduct, in every space it uses: issues, pull requests, reviews and commits.

In short: be respectful and constructive, assume good faith, and keep the discussion about the work. Harassment, insults, and personal or political attacks are not accepted.

## Reporting

Use GitHub's own tools, so a report reaches the maintainer and GitHub's moderators without a public reply:

- **Report content** in the `…` menu of a comment, issue or pull request;
- or **Block or report** on the person's profile.

The maintainer may edit or remove content, lock a conversation, or block a participant from the repository, in proportion to what happened.
